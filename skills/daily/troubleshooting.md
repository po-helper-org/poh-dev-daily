# Когда Jira не отвечает

Не выдумывай статусы: без Jira дейлик сводится к плану дня и сводке по рассказу, с пометкой «Jira не сверена». Разработчику — одна причина и одно действие из таблицы.

| Признак | Причина | Что сказать разработчику |
|---|---|---|
| Инструментов `jira_*` нет | MCP-сервер `jira` не запустился | Нужен `uv` (`brew install uv` или `pipx install uv`), затем перезапуск Claude Code. Проверка — `/mcp`: сервер `plugin:dev-daily:jira` в статусе connected |
| 401 / Unauthorized | Токен не задан или истёк | Выпустить новый Personal Access Token в профиле Jira и ввести его в `/plugin` → dev-daily → Configure |
| Таймаут, `Connection refused`, ошибка DNS | Jira доступна только из корпоративной сети | Включить VPN и повторить |
| `uvx` не скачивает пакет | Нет доступа к PyPI | Настроить прокси/зеркало PyPI (`UV_INDEX_URL`) и перезапустить Claude Code |
| 403 на переход или комментарий | Нет прав в проекте или workflow запрещает переход | Оставить задачу как есть; назвать в отчёте переход и ошибку |
| Нужного перехода нет в `jira_get_transitions` | Workflow ведёт через промежуточный статус | Перечислить доступные переходы; разработчик выбирает сам |
